# Teen Mental Health Prediction Using Machine Learning

## Overview

Mental health challenges among teenagers have become increasingly linked to lifestyle patterns, social media engagement, sleep habits, stress levels, and digital behavior. This project leverages Machine Learning to predict the risk of depression among teenagers using behavioral and psychological indicators.

The objective is to identify potential risk patterns early and demonstrate how data-driven approaches can support mental health awareness and predictive analytics.

---

## Problem Statement

Can we predict depression risk among teenagers using factors such as:

* Daily social media usage
* Sleep duration
* Anxiety levels
* Stress levels
* Screen time before sleep
* Academic performance
* Physical activity
* Social interaction patterns

This project explores that question through a supervised machine learning pipeline and an interactive prediction application.

---

## Dataset Information

The dataset contains:

* 1,200 records
* 13 attributes
* Behavioral, academic, and psychological indicators
* Binary target variable:

  * 0 → No Depression
  * 1 → Depression Risk

### Features

| Feature                  | Description                       |
| ------------------------ | --------------------------------- |
| age                      | Student age                       |
| gender                   | Gender of participant             |
| daily_social_media_hours | Hours spent on social media daily |
| platform_usage           | Primary platform used             |
| sleep_hours              | Average sleep duration            |
| screen_time_before_sleep | Device usage before sleeping      |
| academic_performance     | Academic performance score        |
| physical_activity        | Physical activity level           |
| social_interaction_level | Level of social engagement        |
| stress_level             | Reported stress level             |
| anxiety_level            | Reported anxiety level            |
| addiction_level          | Social media addiction score      |
| depression_label         | Target variable                   |

---

## Project Workflow

### Data Preprocessing

* Loaded raw dataset
* Encoded categorical variables using LabelEncoder
* Split dataset into training and testing sets
* Preserved class distribution using stratified sampling

### Model Training

Model Used:

* Random Forest Classifier

Special handling:

* Class imbalance addressed using balanced class weighting

### Evaluation Metrics

The model was evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix

## Running the Project

### Clone Repository

```bash
git clone <repository-url>
cd Teen-Mental-Health-Prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Train Model

```bash
python src/train.py
```

### Run Prediction Script

```bash
python src/predict.py
```

### Launch Streamlit Application

```bash
streamlit run app/app.py
```
